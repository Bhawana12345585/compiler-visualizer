# Compiler Visualizer

## Overview

A compiler visualization project demonstrating lexical and syntax analysis concepts used in compiler design.

## Technologies Used

- HTML
- JavaScript
- Node.js
- Lex
- Yacc
- C

## Features

- Lexical Analysis
- Syntax Analysis
- Token Generation
- Compiler Visualization

## Team Project

Developed as a college project by a team of students.

## Learning Outcomes

- Understanding compiler phases
- Lexical analysis using Lex
- Syntax analysis using Yacc
- Backend integration with Node.js
